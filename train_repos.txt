# One repo per line:   <path-or-url>[,<language>]
#   - <path-or-url>  a local git repo path OR a remote URL (cloned once into data/cache/clones)
#   - <language>     OPTIONAL tag (python, javascript, go, ...). Used only for the
#                    leave-one-language-out evaluation that proves cross-language transfer.
# Lines starting with '#' are ignored.
#
# TIPS for a model that actually learns something:
#   * Pool 5-15 repos, each with a few hundred commits (more history = more snapshots).
#   * Mix at least 2-3 languages so you can hold one out and show it still works.
#   * The features are language-agnostic (churn, authors, recency, prior fixes, LOC),
#     so a model trained on Python repos transfers to JavaScript etc.
